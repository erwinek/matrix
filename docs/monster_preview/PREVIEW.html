MONSTER 3 IN 1 — symulator urządzenia

Zagraj w całe urządzenie: wrzuć monety, wybierz grę i uderzaj. Ekran 96×96, słup Hammera 64×512 i wyświetlacz COINS działają jak w maszynie. Cyfry nakłada symulator (tak jak zrobi to sterownik).

Ekran A 96×96
Hammer 64×512
Wyświetlacz kredytów

Zasady: 1–2 kredyty → tylko SINGLE (START KICKER). 3+ kredytów → wybór: START BOXER = turniej (−3), START KICKER = single (−1). Turniej: BOXER → START KICKER → KICKER → START HAMMER → HAMMER → wynik. Poziom destrukcji Hammera = wynik zaokrąglony w dół do setki (min. 100). Progi zakończeń (GOOD/GREAT/MONSTER/RECORD) są przykładowe.

Wszystkie animacje

Kliknij kartę, żeby obejrzeć ją na ekranie powyżej (zatrzymuje grę).
